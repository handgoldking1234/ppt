# 장표 스튜디오

기획안을 넣으면 AI가 발표·제안서 장표를 만들고, 테마와 요소를 피그마처럼 직접 고칠 수 있는 웹 프로그램입니다.

- AI 자동 생성: 입력 → 목차 검토 → 장표 생성, 테마 추천
- 테마 편집: 색·글꼴·레이아웃·모서리·차트 색 (문서별, 기본값 되돌리기)
- 피그마식 편집: 레이어, 도형, 펜, 정렬, 그림자·블러 효과
- PPTX·HTML 불러오기: 요소별로 편집 가능하게 변환

## 실행

`index.html` 하나로 동작합니다. 빌드 없이 Vercel에 바로 배포할 수 있습니다.

## 참고

AI 기능은 Claude 아티팩트 안에서 실행할 때만 동작합니다. 일반 웹 주소에서는 AI 없이 로컬 기능으로 동작합니다.
