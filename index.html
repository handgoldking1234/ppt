AI 자동 생성 기능 비교

모두 "입력 → (개요) → 테마 → 생성 → 편집" 순서를 따릅니다. 차이는 입력을 얼마나 존중하는지, 생성 전에 무엇을 고칠 수 있는지, 생성 후 AI를 어디에 다시 쓸 수 있는지에서 납니다.

장표 스튜디오의 AI 생성 흐름

입력

기획안·주제·파일 중 하나와 분량, 구성 양식, 형식(발표·제안서, 가로·세로), 페이지 수, 대상 청중, 말투를 고릅니다.

개요 확인

AI가 짠 페이지 목록을 보고 제목·내용·장 종류를 고치고, 드래그로 순서를 바꾸고, 빼거나 더합니다. AI 추천 테마가 표시됩니다.

생성 · 다듬기

테마 레이아웃 엔진이 즉시 배치하고 기획안에도 반영합니다. 이후 페이지마다 "짧게·설득력 있게·격식 있게" 같은 AI 다듬기를 씁니다.

차별화 포인트

  • 1
    주제가 아니라 기획안을 입력받는다헤딩은 섹션, 항목은 본문, 수치는 지표 카드, "1주차: …"는 일정표로 판별해 원래 논리 구조를 유지합니다.
  • 2
    발표와 제안서를 다른 문법으로발표는 한 장 한 메시지·큰 글씨, 제안서는 목차·섹션 번호·머리말·쪽번호가 붙는 A4 문서. 가로·세로 모두 지원.
  • 3
    테마 = 색이 아니라 레이아웃 체계헤더 띠형, 좌우 분할형, 에디토리얼형, 카드 그리드형으로 배치 자체가 다시 짜입니다.
  • 4
    피그마와 같은 손맛의 편집같은 도구 구성과 단축키, 스마트 가이드, Alt 거리 측정, 그룹, 우클릭 메뉴.
  • 5
    내가 만든 차트·다이어그램을 테마에 맞춤피그마에서 SVG로 복사해 붙이면 원본 색이 테마 팔레트로, 서체가 테마 서체로 바뀝니다.
